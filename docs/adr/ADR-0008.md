# ADR-0008: Offline-First, Deterministic-First Evaluation

**Status:** Accepted
**Date:** 2026-10-03

## Context

Evaluation is the project's differentiator, but default CI must run without paid model
credentials, and stochastic judge scores must not hide hard safety failures.

## Decision

1. `evals/` is a first-class package with versioned JSONL datasets, deterministic
   evaluators, a runner and JSON + Markdown reports.
2. Every report records: git SHA and dirty flag, dataset version and SHA-256, config,
   model/provider + version, prompt version, embedder version, retrieval config, seeds,
   example counts, environment, timestamps, raw per-example results, aggregates with
   bootstrap confidence intervals, failures and exclusions.
3. Metrics are reported separately per category. **Safety invariants are hard gates**
   (any unauthorized execution, approval bypass, cross-tenant leak or secret leak fails the
   run) from day one. Quality thresholds are configured only after a baseline exists.
4. The default system under test is the deterministic offline stack (deterministic model
   provider + hashing embedder). Vendor models are opt-in via environment and are never
   required by CI.
5. LLM-as-judge is used only for semantic answer quality, with a versioned rubric, a
   calibration set, human-agreement measurement, and recorded judge cost/latency. Judge
   scores are reported as estimates, never as ground truth.

## Alternatives considered

| Option | Trade-off |
|---|---|
| Adopt RAGAS/DeepEval wholesale | Fast start, but most needed metrics are deterministic and simpler to own; framework judges hide rubric/version details. |
| Single aggregate score | Easy to chart; hides critical failures. Rejected. |
| Run LLM evals on every PR | Cost and nondeterminism; smoke suite on PR, full suites on schedule/release. |

## Consequences

- The offline baseline measures the *deterministic* pipeline. It is a floor and a
  regression guard, not a claim about LLM-backed quality.
- Small synthetic datasets produce wide confidence intervals; reports state sample sizes
  and avoid significance claims.
