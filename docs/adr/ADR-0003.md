# ADR-0003: Go CLI for Developer Interface

**Status**: Accepted  
**Date**: 2026-08-04

## Context

The command-line experience must be fast, portable, and easy to distribute in enterprise environments.

## Decision

Use Go with Cobra (and optional BubbleTea) for the CLI.

## Alternatives

- Python Click
- Node.js Commander
- Java picocli

## Rationale

Go enables static binaries, fast startup, cross-platform builds, and straightforward release distribution.

## Consequences

CLI release automation must build multi-platform artifacts and maintain backward-compatible command UX.
