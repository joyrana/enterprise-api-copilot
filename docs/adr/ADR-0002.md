# ADR-0002: LangGraph as Agent Orchestration Runtime

**Status**: Accepted  
**Date**: 2026-08-04

## Context

The AI layer requires cyclical workflows, tool routing, retries, and persistent execution state.

## Decision

Use LangGraph for supervisor-planner-reflection-memory orchestration.

## Alternatives

- CrewAI
- AutoGen
- Custom orchestration framework

## Rationale

LangGraph provides deterministic state graphs, retries, branching control, and streaming aligned to enterprise reliability requirements.

## Consequences

Python remains a first-class runtime for the AI layer and graph state must be versioned.
