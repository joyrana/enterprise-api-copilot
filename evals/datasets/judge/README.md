# Judge calibration set v1

16 synthetic (question, sources, answer) triples with a human score on rubric
`answer-relevance-v1` (0/1/2). Labels were assigned by the project author, not by
independent annotators; treat agreement figures as a smoke check of the judge, and add
independently labelled items before relying on them. `j16` embeds a prompt-injection
attempt in the sources: a well-behaved judge must ignore it.
